## 4. Edge cases & negative flows (ranked by severity)

### Critical
1. **Single-user mode silent auth bypass** — `api/context.py` (`get_current_user`): when `RIZWAN_SINGLE_USER_MODE=1`, every request is short-circuited to `user_001` with no JWT validation and no audit log. Combined with Railway env-var drift this is a tenant-isolation footgun. **Fix:** require an explicit `BIND_USER_ID=user_001` startup env (asserted at boot) before allowing the bypass; log a WARNING line on every short-circuit.
2. **Cost cap not enforced inside the worker** — `api/worker.py` only checks the cap at API ingress; long-running G2 builds can exceed `G2_MAX_COST_USD` between checkpoints. **Fix:** in `g2_run.py` after each node, sum `transcript.cost_usd_so_far` and abort if `> max_cost_usd`. Persist `cost_so_far` on `jobs_runs` for visibility.
3. **Duplicate enqueue race** — two concurrent `/jobs/{id}/generate-resume` calls can both pass the idempotency check and produce two paid builds. Idempotency key in `api/queue.py` is `sha256(user_id|kind|payload)` and **does not include `job_id`**; payload-equal cross-job collisions are also possible. **Fix:** include `job_id` in the hash; add a unique partial index `(user_id, job_id, kind) WHERE status IN ('queued','running')`.
4. **File upload OOM** — `api/network.py` `/import/linkedin-csv` reads the entire file into memory with no size or MIME check. **Fix:** stream-parse with `csv.reader`, cap at 10 MB, validate `text/csv`.
5. **Signed-URL expiry of 365 days** — `db/client.py` `upload_artifact()`. After job archive or revoke, link is still valid for 11+ months. **Fix:** drop to 7 days; refresh on demand from a server endpoint that re-checks ownership.

### High
6. **Worker `_is_retryable()` conflates programmer + transient errors** — `ValueError` from a truncated LLM JSON response is treated as non-retryable, exhausting the request. Pattern-match the message or differentiate `JSONParseError`.
7. **APScheduler `misfire_grace_time=300` allows double-fire** — `main.py` cron jobs that take longer than the grace will be re-run. Set `coalesce=True` and `max_instances=1` per job.
8. **Persona quality gate ignores age** — `api/actions.py` returns `score_high_no_resume` based on persona quality but not freshness. Treat persona older than 30 days as stale.
9. **`_parse_json_loose` has no retry / schema validation** — `agents/llm_router.py:573-597` raises raw `json.JSONDecodeError` on bad responses. `ask_json` should retry with a "respond with strict JSON only" reminder, then fall back to a sentinel. Optional schema arg using pydantic would catch missing keys.
10. **Cost cap interaction with `force=true`** — `api/workspace.py` lets `force=true` rebuild bypass the persona gate AND inherit the prior $5 cap; a previously-failed $4.99 build leaves only 1¢ for the next attempt. Reset cumulative spend on terminal-state retries.

### Medium
11. **`ilike(...)` not escaping `%` / `_`** in network search → pattern-injection. Use `.replace("%", "\\%").replace("_", "\\_")` and pass `escape='\\'`.
12. **Empty / oversized prompt validation absent** in `agents/base_agent.py`. Assert non-empty prompt and bound on response.
13. **`/save-resume-edit` accepts up to 65 KB** without checking total resume size. Cap at 20 KB combined; pre-count tokens.
14. **`api/interview_studio.py` parses interview responses without validating `question_id`** — KeyError → 500. Use a Pydantic model (FastAPI returns 422 automatically).
15. **DST handling in scheduler** — fixed-offset timezones in `main.py` cron triggers can skip / repeat jobs. Use IANA names (`Asia/Dubai`) consistently and add a "missed-since" reconciliation step.
16. **Provider fallback in router doesn't track per-provider error rates** — cascading 429s. Add a 5-minute sliding error window and skip dead providers.

### Low
17. **Generic exception handler in `api/server.py` returns `str(exc)`** — Supabase exceptions can include connection strings. Redact + log server-side only.
18. **`/actions/today` returns full job descriptions** (potentially 1 MB). Return `(job_id, title, company, score)` only; fetch detail on demand.
19. **`boss_agent` cron iterates all users without `is_active` filter** — runs work for soft-deleted accounts.
20. **Pydantic deprecation warnings** (50 of them) — `Field(..., env=...)` will break under Pydantic v3. Migrate to `Field(..., json_schema_extra=...)` or use the `pydantic-settings` `Settings` env-binding pattern.
21. **Lint: missing useCallback deps** — `dashboard/src/components/workspace/ResumeEditor.tsx:422` and `RoleOverviewTab.tsx:58`. Either add the deps or disable the rule for that line with a why-comment.

## 5. Test coverage — top 15 missing tests

> All entries are concrete: name the function under test, the negative condition, and where it lives.

1. `agents/llm_router.py::ask` — provider timeout (httpx ReadTimeout) → assert it raises a typed `LLMTimeoutError`, not a bare `Exception`.
2. `agents/llm_router.py::ask` — 429 response → assert backoff + retry, capped at N attempts, then typed `LLMRateLimitError`.
3. `agents/llm_router.py` — missing `ANTHROPIC_API_KEY` → `_get_client` raises a startup-friendly `ConfigError`, not `KeyError`.
4. `resume_agents/g2_run.py::run` — `target_profile=None` and `job_posting=""` → fail fast at entry, not in node 4.
5. `resume_agents/g2_run.py` — concurrent runs hitting cost cap → only one wins; the other gets a clean `CostCapExceeded`.
6. `resume_agents/g2_nodes.py::_run_ats_critic` — malformed JSON return → bounded retry, then sentinel; no infinite loop.
7. `interview_agents/g3_nodes.py::merge_questions` — Jaccard=1.0 (all duplicates) → returns the original set, not `[]`.
8. `interview_agents/g3_nodes.py::star_story_matcher` — empty story bank → returns generic placeholders, not `None`.
9. `agents/persona_synthesizer.py::run` — LLM returns invalid JSON → graceful failure + retain prior persona; persona_version not incremented.
10. `agents/persona_synthesizer.py::run` — concurrent synthesis on same `company_id` → atomic version increment, no Supabase 409 left unhandled.
11. `agents/cost_alerter.py::check_daily_spend` — Slack 5xx → falls back to SendGrid; alert is not lost.
12. `api/queue.py` — duplicate enqueue races → idempotency wins exactly once (needs the `job_id` in the hash fix from §4.3 first).
13. `api/worker.py` — worker crash mid-job → orphan reaper picks up; retry doesn't pay twice; cost ledger preserved.
14. `api/network.py::/import/linkedin-csv` — 200 MB binary upload → 413, not OOM.
15. `evals/regression_check.py::compare_reports` — NaN axis delta → flagged, not silently passing.
